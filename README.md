# Superstore-Sales-Performance-Profitability-Dashboard
An interactive Tableau dashboard analyzing retail sales data to uncover key business insights.

## 📋 Project Overview
This project demonstrates end-to-end data analysis and visualization skills by building a professional business intelligence dashboard for a fictional retail superstore.

### 🎯 Key Features
- **KPIs**: Total Sales, Total Profit, Profit Margin, Total Orders, Avg Discount
- **Time Analysis**: Monthly sales and profit trends (dual-axis chart)
- **Category Analysis**: Performance breakdown by product category
- **Geographic Analysis**: Sales distribution by state (filled map)
- **Top Performers**: Top 10 products by profit
- **Interactive Filters**: Region, Category, Segment, and Year

## 🛠️ Tools & Technologies
- **Tableau** (Primary visualization tool)
- **Excel + Power Query** (Data cleaning and preparation)
- Data Visualization & Dashboard Design
- Business Metrics & Insights Generation

## 📊 Key Insights
- Technology category drives the highest profit while Furniture shows lower margins
- Clear seasonal patterns in monthly sales
- Significant regional variations in performance (e.g., high-performing states)
- Discount strategy analysis and its impact on profitability
